# TakumiCAD

BIM software for Japanese timber houses (在来軸組) — plans, sections, elevations, structure checks, MEP, kitchens and permit documents from one model.

日本の木造住宅のための BIM ソフト。平面図・立面図・断面図、壁量計算、設備図、キッチン、確認申請図書をひとつのモデルから作成できます。

- **Download / ダウンロード (free / 無料):** [latest release](https://github.com/takumicad/takumicad-releases/releases/latest) — Windows 10/11 64-bit
- **Support / 応援:** [ofuse.me/takumicad](https://ofuse.me/takumicad)
- **Issues / 不具合報告:** [GitHub Issues](https://github.com/takumicad/takumicad-releases/issues)

Free software, provided as is, without warranty. Permit, structural and energy documents must be checked, signed and submitted by a licensed architect (建築士).

無償のソフトウェアです（現状有姿・無保証）。確認申請・構造・省エネの図書は、必ず建築士が確認・記名のうえ提出してください。
